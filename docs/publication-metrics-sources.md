# Publication metric sources

Checked on 6 November 2026. Journal impact factors below are Clarivate JCR
values for the year of first online publication. When that differs from the
issue year, both dates are shown. JCR releases each year's factor the following
year. Conference rates are for the stated conference edition and track;
percentages are rounded to one decimal where necessary. These values are also
used in the CV repository.
